# Decision log (ADRs)

One short file per significant decision: context, decision, alternatives rejected, consequences. Number them `0001-title.md`.

Until they are written up, decisions are recorded in `HANDOVER.md` Session Log entries (headed **Decisions** or "DECISION"). Candidates for the first ADRs: three environments with build-time data root (v2.1.0 / v2.7.1); parent/child eating model (v2.6.5); portion-based RAG rules in code (D11); analyse-and-discard for photos (v2.12.0); the Open pattern and button standard (v2.8.0 / v2.13.0); AI usage ledger as the source for Companion Energy (v2.14.0).
